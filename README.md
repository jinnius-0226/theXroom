# X ROOM : 나의 X를 정리하는 시간

영화 <실연당한 사람들을 위한 일곱 시 조찬모임> 인터랙티브 웹 프로모션 프로토타입.

- `index.html` — 배포용 단일 페이지 (Three.js r128, CDN)
- `src/` — 원본 스크립트 (`python3 build.py`로 index.html 생성)
- `assets/` — 공식 포스터·스틸컷·예고편(720p)
- `vendor/trystero.js` — 서버 없는 브라우저 간 연결(Trystero, nostr 신호)

## 동시 접속
- 공간(X ROOM / GOODBYE / DELETE / ARCHIVE)마다 방을 나누고, 한 방에 30명이 차면 다음 방(`-2`, `-3`…)으로 자동 이동합니다.
- 다른 방문자의 캐릭터·손흔들기와 편지·꽃·동전·소각·노트·다트·낙서가 실시간으로 공유됩니다.
- 별도 서버가 없으므로 기록은 접속 중인 사람끼리 주고받고, 새로 들어온 사람에게 최근 기록을 넘겨줍니다. 아무도 없을 때의 기록은 각자 브라우저에만 남습니다.

## 소재 교체
`src/core.js` 상단의 `CONFIG`에서 문구·포스터·스틸컷·예고편 경로를 바꾼 뒤 `python3 build.py`.
